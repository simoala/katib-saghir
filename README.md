# ورشة الكاتب الصغير

ورشة تفاعلية لتلاميذ المستوى السادس ابتدائي لإنجاز الإنتاجات الكتابية الاثني عشر (المسار الثالث – دعم التعلمات الأساس).

- اختيار الإنتاج وعرض المهمة وعناصر «قبل أن أكتب».
- ورقة مسطّرة مع عدّاد الكلمات والجمل والأسطر.
- مدقّق سريع للأخطاء الشائعة مع زر «أصلح».
- تصحيح إملائي ونحوي عبر خدمة LanguageTool المجانية.
- جدول «أراجع كتابتي» وحفظ تلقائي للمسودات في المتصفح.

الموقع: https://simoala.github.io/katib-saghir/
